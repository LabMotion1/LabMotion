LabMotion – Estudio del movimiento en un plano inclinado

1. Descripción del proyecto

LabMotion es un laboratorio virtual diseñado para estudiar el movimiento de un objeto sobre un plano inclinado mediante los sensores integrados de un smartphone o tablet.

La aplicación permite visualizar datos de aceleración, conocer el ángulo de inclinación, registrar mediciones y comparar los resultados experimentales con valores teóricos.

2. Objetivo

Analizar la relación entre el ángulo de inclinación de un plano y la aceleración, utilizando los sensores de movimiento de un dispositivo móvil.

3. Fundamento científico

El modelo matemático utilizado es:

a = g · sen(θ)

Donde:

* a: aceleración teórica (m/s²).
* g: aceleración de gravedad (9,81 m/s²).
* θ: ángulo de inclinación (grados).

4. Variables del experimento

* Variable principal: aceleración (m/s²).
* Variable complementaria: ángulo de inclinación (°).
* Instrumento de medición: acelerómetro integrado en smartphone o tablet.

5. Tecnologías utilizadas

* HTML5: estructura de la aplicación.
* CSS3: diseño y adaptación a dispositivos móviles.
* JavaScript: procesamiento de datos y cálculos.
* DeviceMotionEvent: acceso a datos de movimiento.
* DeviceOrientationEvent: acceso a datos de orientación.
* GitHub: almacenamiento y control de versiones.
* GitHub Pages: publicación de la aplicación web.

6. Instrucciones de uso

1. Ingresar a la aplicación LabMotion.
2. Colocar el dispositivo sobre el plano inclinado.
3. Presionar “Iniciar acelerómetro”.
4. Autorizar el acceso a los sensores si el navegador lo solicita.
5. Observar los valores de aceleración X, Y y Z y el ángulo.
6. Presionar “Registrar medición”.
7. Repetir el procedimiento para obtener al menos cinco mediciones.
8. Seleccionar “Ver resultados”.
9. Revisar y comparar los resultados experimentales y teóricos.
